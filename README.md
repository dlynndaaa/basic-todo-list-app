## 🚀 Key Features
- **Add New Tasks:** Insert new tasks into the list.
- **Mark as Done:** Visually mark completed tasks.
- **Delete Tasks:** Dynamically remove tasks from the list.

## 🛠️ Technologies Used
- **HTML5:** Structures the main web page.
- **CSS3:** Styles the user interface to be neat, attractive, and interactive.
- **Vanilla JavaScript:** Handles the application logic for real-time user interactions without page reloads.

## 💻 How to Run Locally

If you want to run or modify this code on your local machine:

1. Clone this repository using your terminal:
   ```bash
   git clone https://github.com/dlynndaaa/basic-todo-list-app.git
2. Open the project folder in your favorite code editor (e.g., Visual Studio Code).
3. Open the index.html file directly in your browser, or use the Live Server extension in VS Code for an optimal development experience.
